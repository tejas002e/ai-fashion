# AI Fashion Color Recommender

A high-end fashion e-commerce styled AI personal stylist.

## Features
- AI Skin Tone & Undertone Analysis
- Computer Vision (OpenCV) Face Detection
- Personalized Color Recommendations
- E-commerce Style UI (Inspired by Myntra/H&M)
- Animated Interactive Experience

## Tech Stack
- Python (Streamlit)
- OpenCV (Haar Cascades)
- Scikit-Learn (KMeans Clustering)
- Custom CSS/HTML

## How to Run
```bash
pip install -r requirements.txt
streamlit run main.py
```
